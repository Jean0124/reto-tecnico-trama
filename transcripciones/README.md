# Transcripciones

Tres entrevistas reales con el modelo (`gpt-4.1-mini`), exportadas desde la app con el botón del encabezado. Cada archivo incluye la conversación completa y el requerimiento confirmado en JSON.

1. [`01-rotacion-de-personal.md`](01-rotacion-de-personal.md): renuncias en operaciones; decisión entre turnos o supervisores.
2. [`02-pedidos-tarde.md`](02-pedidos-tarde.md): entregas tarde y reclamos; decisión entre más repartidores o rearmar rutas.
3. [`03-inventario.md`](03-inventario.md): diferencias entre el ERP y los conteos físicos; decisión entre cambiar el registro de salidas o contar más seguido.

En las tres el usuario pide una cifra (causa, porcentaje o pérdida en plata) y el agente no la da, y pide un ajuste que genera una versión nueva del requerimiento.
